= Mobile target

The mobile client MUST be built with *Tauri 2.0+* or *Dioxus* (Rust-first),
per the estate language policy. Kotlin/Gradle/Swift are banned for mobile.

The previous Kotlin/Gradle Android client (`android/`) was removed on
2026-06-24 as a policy violation (recoverable from git history if any logic
needs porting). Rebuild the mobile target in Tauri/Dioxus.
